### Complete List of Commit Types

#### Core Structural Types

`feat`: Introduces a brand new feature to the codebase.

`fix`: Patches a bug or resolves an issue in the application.

#### Technical & Structural Changes

`refactor`: Rewrites or restructures production code without changing its external behavior or fixing a bug.

`perf`: A specific type of refactor intended strictly to improve execution performance.

`style`: Updates code formatting, missing semicolons, or whitespace (no production logic changes).

`test`: Adds missing tests, updates test cases, or refactors existing test suites.

#### Project Maintenance & DevOps

`chore`: General maintenance tasks like updating dependencies, config tweaks, or routine updates that do not alter source files.

`build`: Changes that modify the build system, external dependencies, or package management scripts (e.g., npm, webpack, gradle).

`ci`: Edits to Continuous Integration files, automation workflows, and pipelines (e.g., GitHub Actions, CircleCI, Travis).

#### History & Documentation

`docs`: Changes restricted entirely to documentation, such as README files, wikis, or internal code comments.

`revert`: Reverts a previously merged commit back to a historical state.
